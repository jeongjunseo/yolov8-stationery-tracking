## 6. 객체 감지 및 추적 결과

학습된 `best.pt` 모델의 검출 결과를 ByteTrack에 전달하였다. 프레임 사이에서 유지되는 track ID를 기준으로 객체 중심점의 이력을 저장하고, 최근 중심점들을 선으로 연결해 이동 궤적을 표시하였다.

- 입력 영상 길이:
- 결과 영상 길이: 5초
- confidence threshold:
- tracker: ByteTrack
- 결과 영상: `outputs/final_5s.mp4`
- 궤적 좌표: `outputs/trajectory.csv`

영상의 대표 프레임을 삽입하고 클래스명, 신뢰도, ID, 궤적이 표시되는지 설명한다. 객체가 겹치거나 화면 밖으로 나갔을 때 ID가 바뀐 사례가 있다면 함께 기록한다.
